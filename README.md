# Student Registration - Flask CRUD App

A simple CRUD (Create, Read, Update, Delete) web application built with 
Flask and SQLAlchemy for managing student registration records.

## Features
- Add new student records (Name, Email, Course, Age)
- View all registered students in a table
- Edit/update existing student records
- Delete student records
- Flash messages for success/error feedback
- SQLite database (auto-created on first run)
